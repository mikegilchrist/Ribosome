# Ribosome

R package behind the polysomeModel manuscript.

## What the model is

The model gives the steady-state distribution of mRNA over polysome classes
0 to imax (the number of bound ribosomes). Capped (unmarked) mRNA is produced
at rate lambda, gains ribosomes by initiation (kappa), loses them by
elongation and termination (tau, elongation rate in codons per second), and is
decapped at rate mu. Decapped (marked) mRNA keeps the ribosomes it had and is
degraded from the ribosome-free class at rate delta. Termination scales with the
number of ribosomes; initiation is either density independent (DII,
`which.interfere = "tau"`) or density dependent (DDI, the default). The capped
distribution comes from a tridiagonal linear solve and the decapped one from
cumulative sums of the capped one.

## Install

From GitHub (needs the `remotes` package):

    remotes::install_github("mikegilchrist/Ribosome")

or from a clone, in a shell:

    R CMD INSTALL .

The only hard dependency is `limSolve` (plus base `graphics` and `grDevices`).
`testthat` and `data.table` are suggested. The License field in `DESCRIPTION`
is still a placeholder; the authors have not chosen one.

## Tests

From the repo root:

    Rscript -e 'testthat::test_dir("tests/testthat")'

`R CMD check` also runs them; tests that need repo-only files (the retired
scripts and the reference solver) are skipped, with the reason stated, when run from the installed
package. See `tests/testthat/KNOWN_FAILURES.md` for known defects the tests
document.

## Repo layout

- `R/` the package: `Polysome_functions_RAUC.R` (solver and summary
  statistics) and `Ribosome-package.R` (package doc and imports).
- `man/`, `NAMESPACE` generated by roxygen2 (`Rscript -e 'roxygen2::roxygenise()'`).
- `tests/` testthat tests and golden reference values.
- `Text/` `Paper final figures.Rmd`, the source of the manuscript's model figures.
- `inst/scripts/` analysis scripts that are not package code (they read data
  and call `setwd()`); see its README.md.
- `retired/` superseded code kept for review; see its README.md.
- `Claude.Code_*` docs at the root: the handoff brief, the code map
  (figure to code, function status), the figure review notes, and a reference
  solver used as an independent check.

## Regenerating the manuscript figures

All model figures come from `Text/Paper final figures.Rmd`, which sources
`R/Polysome_functions_RAUC.R`. The parameter grid is `CreateParMatrix`
(`expand.grid`), so kappa (`seq(0.0001, 0.5, 0.0001)`, 5000 values) varies
fastest and each 5000-row block is one mu. Model figures use tau = 1,
lambda = 1, delta = 1e5, imax = 39 (yeast median) unless stated.
Chunk names below are the Rmd's own labels, which do not match the paper's
figure numbers. Source: `Claude.Code_2026-10-09_v1.0_code.map.md` Section 2,
where the mismatches between code and captions are listed.
